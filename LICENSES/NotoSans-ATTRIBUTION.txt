Noto Sans Font Attribution
==========================

This software bundles Noto Sans font files under resources/fonts/:

  resources/fonts/NotoSans.ttf
  resources/fonts/NotoSans-Medium.ttf
  resources/fonts/NotoSans-DemiBold.ttf
  resources/fonts/runtime/NotoSansArabic-Regular.ttf
  resources/fonts/runtime/NotoSansDevanagari-Regular.ttf
  resources/fonts/runtime/NotoSansHebrew-Regular.ttf
  resources/fonts/runtime/NotoSansJP-Regular.ttf
  resources/fonts/runtime/NotoSansKR-Regular.ttf
  resources/fonts/runtime/NotoSansTC-Regular.ttf

The files under resources/fonts/runtime/ are static Regular instances cut
from the upstream variable fonts with fontTools; see the README there.

Sources:

  Noto Sans / Noto Sans Arabic / Devanagari / Hebrew
  https://github.com/notofonts/

  Noto Sans CJK (JP, KR, TC)
  https://github.com/notofonts/noto-cjk
